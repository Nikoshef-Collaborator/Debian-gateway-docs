# scripts/ - готовые файлы

Здесь лежат те же скрипты, юниты systemd и конфиги, что и в блоках
`tee ... <<'EOF'` в документации (`docs/`), - вынутые в отдельные файлы,
чтобы их было удобно читать и сравнивать. **Эталон - документация**: файлы
здесь собираются из неё автоматически, и если они разошлись - верь `docs/`.

Пути повторяют места на машине:

- `gateway/...` - шлюз (Debian 13). Файл `gateway/usr/local/sbin/gw-nat.sh`
  ставится в `/usr/local/sbin/gw-nat.sh`.
- `vps/...` - свой VPS (Ubuntu), Части 06 и 07.

## Перед установкой

1. Ставь по документации, по порядку Частей - там сказано, что, когда и
   какой командой включать. Простое копирование всей папки шлюз не поднимет.
2. Файлы `*.example` - шаблоны с секретами. Убери `.example` и подставь
   свои значения вместо `ПОДСТАВЬ_...`:
   - `gateway/etc/gateway/tg.conf.example` - токен бота и chat id (Часть 2);
   - `gateway/etc/gateway/pool/warp-wgcf-1.conf.example` - ключ WARP (Части 2, 5);
   - `vps/etc/amnezia/amneziawg/awg1.conf.example` - ключ сервера и
     параметры маскировки. ⛔ `Jc/Jmin/Jmax/S1-S4/H1-H4` придумай свои
     (правила - Часть 5), не бери из примера.
3. `gateway/etc/gateway/gateway.conf`, `dnsmasq.d/lan.conf`, `10-wan.link`,
   `10-lan.link` - проверь имена сетевых карт, MAC-адреса и подсети под себя.
4. Скрипты - `chmod 755`, конфиги с секретами - `chmod 600`.

## Что откуда

| Часть | Что |
|---|---|
| 01 | сеть, NAT, файрвол, DNS (dnsmasq + dnscrypt-proxy) |
| 02 | туннели, полосы, оркестратор, фидер списков, ротация WARP, уведомления |
| 03 | управление: OliveTin, пул WARP, перенос доменов между полосами |
| 04 | netwatch - журнал сбоев сети |
| 05 | warp-bench - замер конфигов WARP |
| 06 | VPS: AmneziaWG-сервер, nftables, бэкап VPS, защита от CVE-2026-98432 |
| 07 | Caddy (сайт и фото) |
| 08 | бэкап Immich |

Отдельные инструменты (PPPoE, патчи, экспорт для git) - в `tools/`.
