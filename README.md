# Домашний шлюз на Debian 13: AmneziaWG + WARP + свой VPS

Документация и вспомогательные скрипты домашнего шлюза: весь трафик дома
идёт через сервер на Debian 13, который раскладывает его по полосам -
напрямую (российские сервисы), через Cloudflare WARP (по умолчанию) и через
свой VPS на AmneziaWG (резерв, ИИ-сервисы, мессенджеры).

Документация написана так, чтобы по ней мог работать даже простой ИИ-помощник:
пошагово, одна команда на блок, с ожидаемым результатом и точками остановки.

| Папка | Что внутри |
|---|---|
| [`docs/`](docs/) | Части 00-09. Начинать с [`00-README-карта-и-правила.md`](docs/00-README-карта-и-правила.md) |
| [`scripts/`](scripts/) | все скрипты, юниты systemd и конфиги из документации - отдельными файлами, по путям на машине (`gateway/`, `vps/`) |
| [`tools/`](tools/) | отдельные скрипты: PPPoE со стражем-откатом, Telegram-уведомления, патч фидера списков, счётчики для сайта, выгрузка конфигов без секретов |

Во всех примерах вместо реальных адресов, ключей и имён - заглушки
`ПОДСТАВЬ_...`. Ключи, пароли и конфиги туннелей сюда не входят.
